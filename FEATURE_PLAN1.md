### План по улучшению UX и реструктуризации интерфейса

**1. Цель**

Провести рефакторинг пользовательского интерфейса для повышения интуитивности и предотвращения ошибок. Основные задачи:
1.  **Визуально разделить** рабочие процессы на логические блоки.
2.  **Реализовать взаимное исключение** между режимами выбора приложений (ручной vs. папка).
3.  **Добавить визуальную обратную связь** о выбранной папке.

**2. Новая структура UI: Концепция трех блоков**

Интерфейс будет перестроен с использованием `tk.LabelFrame` для создания следующих визуальных блоков:

*   **Блок 1: «Отчет»**
    *   Содержит все элементы для выбора основного отчета (`.docx` или `.pdf`).
    *   Включает поля для редактирования имени и кнопки выбора файлов.

*   **Блок 2: «Приложения» (Ручной режим)**
    *   Содержит 6 слотов для индивидуальной загрузки PDF-приложений.
    *   Включает кнопку **«📚 Создать общий PDF»**, которая работает с данными из Блока 1 и Блока 2.

*   **Блок 3: «Приложения из папки» (Автоматический режим)**
    *   Содержит кнопку **«Выбрать папку»** для выбора директории с файлами.
    *   Включает метку для отображения пути к выбранной папке.
    *   Содержит кнопку **«🗂️ Создать PDF из папки»**, которая работает с данными из Блока 1 и Блока 3.

*   **Глобальный сброс:**
    *   Единственная кнопка **«🔄 Сброс»** будет расположена вне блоков и будет очищать все поля и выборы во всех трех блоках.

**3. Технические изменения в `pdf_attachments_ui.py`**

*   **Реструктуризация layout:** Переместить существующие виджеты в соответствующие `tk.LabelFrame`.
*   **Глобальная переменная `folder_for_merge_path`:** Для хранения пути к выбранной папке.
*   **Новая функция `select_folder_for_merge()`:**
    *   Вызывается кнопкой "Выбрать папку".
    *   Использует `filedialog.askdirectory()` для выбора папки.
    *   Сохраняет путь в `folder_for_merge_path` и обновляет метку.
    *   **Вызывает `clear_individual_attachments()` для сброса 6 ручных слотов.**
*   **Новая функция `clear_individual_attachments()`:** Очищает все 6 полей для ручного выбора PDF.
*   **Новая функция `clear_folder_for_merge()`:** Очищает `folder_for_merge_path` и соответствующую метку.
*   **Модификация `select_file(index)`:** При выборе файла в одном из 6 слотов, **должна вызывать `clear_folder_for_merge()`**.
*   **Модификация `create_merged_pdf_from_folder()`:**
    *   Убрать вызов `filedialog.askdirectory()`.
    *   Использовать путь из `folder_for_merge_path[0]`.
    *   Добавить проверку на пустой путь перед выполнением.
*   **Модификация `reset_fields()`:** Должна вызывать `clear_folder_for_merge()` в дополнение к остальным очисткам.

**4. Ключевое требование: Сохранение функциональности**

*   **ВАЖНО:** Все изменения носят исключительно визуальный и UX-характер. Вся базовая функциональность — конвертация Word, создание штампов, обработка страниц с поворотами, и, самое главное, **механизм сборки оглавления (закладок) — должна остаться полностью неизменной и функционально исправной.**

**5. Затрагиваемые модули**
