### План улучшения UX и предотвращения ошибок для функции "Создать PDF из папки"

**1. Цель**

Улучшить пользовательский опыт и предотвратить ошибки путем добавления визуальной обратной связи о выбранной папке и реализации взаимного исключения между режимами выбора приложений (индивидуальные слоты vs. папка).

**2. Изменения в пользовательском интерфейсе (`pdf_attachments_ui.py`)**

*   **Добавить метку для отображения выбранной папки:**
    *   Рядом с кнопкой "🗂️ Создать PDF из папки" будет добавлена новая `tk.Label`.
    *   Эта метка будет отображать путь к выбранной папке или текст "Папка не выбрана".
*   **Добавить кнопку "Выбрать папку для слияния":**
    *   Эта кнопка будет отвечать за вызов диалога выбора папки и обновление метки.

**3. Новые функции и модификации в `pdf_attachments_ui.py`**

*   **Глобальная переменная `folder_for_merge_path`:**
    *   Будет добавлена новая глобальная переменная (например, `folder_for_merge_path = [None]`) для хранения пути к выбранной папке.
*   **Функция `select_folder_for_merge()`:**
    *   Будет создана новая функция, вызываемая кнопкой "Выбрать папку для слияния".
    *   Она будет использовать `filedialog.askdirectory()` для выбора папки.
    *   При успешном выборе папки:
        *   Сохранит путь в `folder_for_merge_path`.
        *   Обновит текст метки `folder_for_merge_label`.
        *   Вызовет `clear_individual_attachments()` для сброса 6 слотов приложений.
*   **Функция `clear_individual_attachments()`:**
    *   Новая функция для очистки всех 6 полей ввода и меток для индивидуальных PDF-приложений.
*   **Функция `clear_folder_for_merge()`:**
    *   Новая функция для очистки `folder_for_merge_path` и обновления `folder_for_merge_label`.
*   **Модификация `select_file(index)`:**
    *   При выборе файла в одном из 6 слотов, эта функция будет вызывать `clear_folder_for_merge()`.
*   **Модификация `create_merged_pdf_from_folder()`:**
    *   Удалить вызов `filedialog.askdirectory()`.
    *   Использовать путь из `folder_for_merge_path[0]`.
    *   Добавить проверку: если `folder_for_merge_path[0]` пуст, выдать ошибку и прервать операцию.
*   **Модификация `reset_fields()`:**
    *   Добавить вызов `clear_folder_for_merge()`.
*   **Модификация `info_text`:**
    *   Обновить текст подсказки, чтобы он отражал новую кнопку "Выбрать папку для слияния" и логику работы.

**4. Затрагиваемые модули**

*   `pdf_attachments_ui.py`: Все изменения будут внесены в этот файл.
