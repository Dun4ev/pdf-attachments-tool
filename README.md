# PDF Attachments Tool (v3.2)

Инструмент для автоматизации работы с PDF‑файлами и документами Word: добавление штампа (текстовой метки) в верхний угол страниц приложений, конвертация Word → PDF и объединение файлов в один итоговый документ.

![Интерфейс программы](assets/screenshot.r2.png)

## Основные возможности

- Выбор основного отчёта: Word (.docx) или PDF.
- Конвертация Word → PDF (при наличии установленного Microsoft Word).
- Обработка до 6 PDF‑приложений: добавление на каждую страницу настраиваемого текста (например, «Prilog / Приложение 7.01») в верхний угол с учётом ориентации и поворота страницы.
- Объединение выбранных файлов (основной отчёт + приложения) в единый PDF.

## Системные требования

- Windows 7/8/10/11
- Microsoft Word (для конвертации .docx → .pdf)

## Установка и запуск

1) Скачайте архив сборки и распакуйте в удобную папку.
2) Запустите `pdf_attachments_ui.exe`.

Для разработчиков: запуск из исходников возможен после установки зависимостей из `requirements.txt`. Инструкции по сборке `.exe` находятся в MANUAL.md.

## Как использовать

1) Выберите основной отчёт (Word или PDF).
2) Заполните подписи для приложений (по необходимости) — например, «Prilog / Приложение 7.01».
3) Выберите до 6 PDF‑файлов приложений.
4) Выберите вариант сохранения: в тот же файл или с переименованием (префикс `att.X_...`).
5) При необходимости сконвертируйте Word → PDF.
6) Нажмите «Создать общий PDF» для объединения в один документ.

Примечания:
- Текст добавляется в верхний угол по короткой стороне «визуально» отображаемой страницы (учитывается `/Rotate`).
- Для сброса полей и путей нажмите «Сброс/Вернуть по умолчанию».

## Устранение неполадок

Проблема: текст штампа «уезжал» на некоторых страницах (Rotate=270 при портретной базе)
- Причина: у страниц с `/Rotate=270` и базовой портретной геометрией (видимая ширина < высоты) визуальная ориентация — альбомная, а базовая система координат остаётся портретной. Без учёта этого штамп позиционировался неверно.
- Решение (v3.2): добавлено обобщённое правило в расчёте якоря — для `/Rotate=270` и портретной базы штамп якорится в визуальном правом верхнем углу, что предотвращает выход за границы. Удалены устаревшие точечные фиксы под конкретный размер 612×792.

Проблема: невидимый текст после сохранения (устаревшая библиотека)
- Решение: переход на `pypdf` вместо `PyPDF2` (исправлено ранее).

## Сборка исполняемого файла

```
pyinstaller --noconsole --onefile --icon=assets/icon.ico --add-data "assets;assets" pdf_attachments_ui.py
```

## Недавние изменения и причина

- Для страниц с `/Rotate=270` и базовой портретной геометрией введено обобщённое позиционирование штампа в визуальном правом верхнем углу (устраняет смещение вправо и выход за границы).
- Добавлена внутренняя переменная `visible_w270` для явного использования «визуальной ширины» при `/Rotate=270` в расчёте `ay`.
- Удалены устаревшие точечные фиксы под 612×792 @ 270° (и закомментированные/отключённые блоки), чтобы не пересекались с обобщённой логикой.

Для разработчиков: подробные детали алгоритма штампа, матриц и координат — в файле `STAMP_VARIANT_A.md`.
