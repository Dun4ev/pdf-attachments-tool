# Анализ проблемы добавления текста в PDF-документы

## 1. Исходная задача

Основная цель — автоматизировать добавление текстовой метки (например, "Prilog / Приложение 7.01") в правый верхний угол каждой страницы для группы PDF-файлов. Эта метка должна корректно отображаться независимо от ориентации и поворота страниц в исходных документах.

## 2. Первоначальная реализация: Метод "Текстового слоя" (Overlay)

Изначально в скрипте использовался метод, основанный на библиотеках `PyPDF2` и `reportlab`.

**Как это работало:**
1.  Для каждой страницы исходного PDF в памяти создавался новый временный PDF-документ ("слой").
2.  На этом слое с помощью `reportlab` рисовался необходимый текст в нужной позиции и с нужным поворотом.
3.  Затем этот слой накладывался поверх оригинальной страницы с помощью `PyPDF2`.

*   **Преимущество:** Этот метод давал полный и точный контроль над визуальным представлением текста. Текст всегда выглядел так, как задумано.
*   **Недостаток:** Текст становился неотъемлемой частью страницы, а не отдельным интерактивным элементом.

## 3. Новая идея: Использование "Текстовых аннотаций"

Было предложено усовершенствовать скрипт, заменив "слои" на стандартные текстовые аннотации PDF (`FreeText`).

**Ожидаемые преимущества:**
*   Текст стал бы интерактивным объектом, который можно выделить или даже отредактировать в программе для просмотра PDF.
*   Такой подход является более "правильным" с точки зрения структуры PDF для добавления подобных меток.

## 4. Реализация и возникшая проблема

Скрипт был переписан для создания и добавления текстовых аннотаций с помощью `PyPDF2`. В процессе тестирования на реальном документе (`CT-CL-B-CS-AIR-II.24.1-00-1M- 20250827-00.pdf`) была выявлена критическая проблема.

**Суть проблемы:**
Документ представляет собой страницу в портретной ориентации, которая повернута на 90 градусов, чтобы выглядеть как альбомная. Программы для просмотра PDF корректно отображают ее, поворачивая для пользователя.

Однако, согласно спецификации PDF, текстовые аннотации должны поворачиваться вместе со страницей. Когда просмотрщик поворачивал страницу для корректного отображения, он **поворачивал и текст внутри нашей аннотации**. В результате текст на странице отображался вертикально, а не горизонтально.

Несмотря на то, что удалось исправить логику и размещать *блок аннотации* в правильном углу, повлиять на *ориентацию текста внутри* этого блока стандартными средствами оказалось невозможно.

## 5. Вывод и рекомендация

Метод с использованием аннотаций, хотя и является более "элегантным" с точки зрения структуры PDF, не обеспечивает необходимого контроля над конечным визуальным результатом для данного конкретного случая.

**Рекомендация:**
Для гарантированного достижения требуемого результата (горизонтальный текст в правом верхнем углу на любых страницах) необходимо **вернуться к первоначальному методу "текстового слоя"**. Он менее интерактивен, но обеспечивает полный контроль и предсказуемость внешнего вида текста.
