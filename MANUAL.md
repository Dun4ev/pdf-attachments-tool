# Инструкция по использованию программы «PDF Приложения»

> **Версия 5.0**
>
> Программа «PDF Приложения» — это инструмент для автоматизации работы с PDF-документами. Она позволяет:
> - Добавлять текстовые штампы (например, «Приложение 7.01») на страницы PDF-файлов.
> - Конвертировать документы Word (.docx) в PDF.
> - Объединять основной отчет (в формате .docx или .pdf) с несколькими PDF-приложениями в один файл.
> - **Автоматически создавать многоуровневое оглавление (закладки)** в итоговом PDF для удобной навигации.

![Скриншот программы](assets/screenshot.r5.png)

## Основной сценарий: Создание общего PDF с оглавлением

Этот сценарий позволяет собрать итоговый документ из отчета и приложений.

1.  **Шаг 1: Выберите основной отчет**
    - **Если отчет в формате Word (.docx):**
        - Нажмите кнопку «📄 Выбрать Word (.docx)» и укажите путь к файлу.
        - Название для закладки будет взято из имени файла, но вы можете его изменить в текстовом поле слева.
    - **Если отчет уже в формате PDF:**
        - Нажмите кнопку «📄 Выбрать PDF (.pdf)» в блоке ниже и укажите путь к файлу.
        - Название для закладки также можно отредактировать.
    > **Важно:** Одновременно можно выбрать что-то одно: либо Word, либо PDF-отчет.

2.  **Шаг 2: Добавьте PDF-приложения**
    - В блоке «Приложения» можно добавить до 6 файлов.
    - Для каждого приложения нажмите «📂 Выбрать PDF» и укажите путь к файлу.
    - В текстовом поле слева можно изменить текст штампа, который будет добавлен на каждую страницу этого приложения (например, `Prilog / Приложение 7.01`). Этот же текст будет использован для создания закладки в оглавлении.

3.  **Шаг 3: Создайте общий PDF**
    - Нажмите зеленую кнопку **«📚 Создать общий PDF»**.
    - Программа попросит вас указать имя и место для сохранения итогового файла.
    - После сохранения внизу окна появятся кликабельные ссылки:
        - **«📎 Открыть ...»** — открывает созданный PDF.
        - **«📁 Открыть папку»** — открывает папку, где лежит файл.

### Результат: PDF с навигацией

Итоговый файл будет содержать:
1.  Страницы основного отчета.
2.  Страницы всех добавленных приложений.
3.  **Кликабельное оглавление (закладки)** для быстрой навигации по документу.

Пример структуры оглавления:
```
- Izvestaj (Ваш отчет)
  - (здесь будут вложены исходные закладки из вашего отчета)
- Prilog 1 - Имя файла приложения 1
  - (здесь будут исходные закладки из первого приложения)
- Prilog 2 - Имя файла приложения 2
  - ... и так далее
```

## Альтернативный сценарий: Сборка из папки

Если у вас много приложений, их можно собрать автоматически из одной папки.

1.  **Шаг 1: Выберите основной отчет** (так же, как в основном сценарии).
2.  **Шаг 2: Нажмите кнопку «🗂️ Создать PDF из папки»**.
3.  **Шаг 3: Выберите папку**, содержащую все нужные PDF-приложения.
    - Программа автоматически найдет, отсортирует по алфавиту и обработает все `.pdf` файлы в этой папке.
    - **Важно:** Файлы, добавленные в 6 ручных слотов, будут проигнорированы.
    - В качестве штампа будет использовано **имя каждого файла без расширения**. Если имя файла слишком длинное, оно будет автоматически сокращено на штампе (с сохранением полного имени в закладках).
4.  **Шаг 4: Сохраните итоговый PDF.**

Этот способ идеально подходит для массовой обработки большого количества приложений.

## Дополнительные функции

### Индивидуальная обработка приложений
Если вам нужно только добавить штампы в PDF-файлы без объединения:
- Выберите файлы в блоке «Приложения».
- Используйте кнопки справа:
    - **«💾 Сохранить в тот же файл PDF»** — перезапишет оригинальные файлы.
    - **«📝 Сохранить с переименованием»** — создаст копии с префиксом `att.X_...`.

### Конвертация Word в PDF
- Выберите Word-файл.
- Нажмите кнопку **«➡️ Создать PDF из word»**.
- Рядом с исходным `.docx` файлом будет создан его PDF-эквивалент.

### Сброс полей
- Кнопка **«🔄 Сброс/Вернуть по умолчанию»** очищает все пути к файлам и возвращает все поля (включая префикс и начальный номер для сборки из папки) к стандартным значениям.
